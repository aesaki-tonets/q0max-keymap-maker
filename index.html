マクロ（M16〜）を作る　※数の上限なし・好きなキーに置ける

M0〜M15 はLauncherで作るマクロ、M16 から先はここで作るマクロです（ファームに書き込むので、電源を切っても焼き直しても消えません）。
作ったマクロは、上の「選んだキーの割り当て」の「マクロ（M16〜）」から、どのレイヤーのどのキーにも置けます。

Launcherのマクロのコードから作る（{+KC_LGUI}{KC_Z}… を貼り付け）

Launcherのマクロ画面の「コード入力」に出るコードを、そのまま貼り付けてください。 {KC_A}＝押して離す、{+KC_A}＝押したまま、{-KC_A}＝離す、{100}＝100ミリ秒待つ、{KC_LCTL,KC_C}＝同時押し、{ } の外の文字＝文字列。

手順は上から順に実行します。「文字列」は半角英数字・記号・改行（Enter）が打てます。貼り付けた全角の英数字や記号は自動で半角に直します。日本語（ひらがな・漢字）はキーボードからは打てません。
文字列を打つときは、パソコンの日本語入力をオフ（半角英数）にしておいてください。オンのままだとひらがなに変換されます。

    QMKのフォルダと直接やり取り（おすすめ）

    保存先：まだ選んでいません

    最初の1回だけ、フォルダ を選びます（1つ上の keymaps フォルダを選んでもOK）。
    フォルダを選ぶ画面で、上のアドレス欄に貼り付けると早いです。
    2回目からはボタン1つで keymap.c を上書き保存／読み込みできます（ブラウザに「許可しますか」と聞かれたら許可）。
    このツールを開くと、まずそのフォルダの keymap.c（本物。ビルドで使われる方）を自動で読み込みます。 手でファイルを編集したときや、他のパソコン・ブラウザで開いたときも、このフォルダの中身が優先されます。 読み込めなかったときだけ、下の「このパソコンに保存」の自動保存から続きを開きます。

    このパソコンに保存（名前を付けて）

    　編集した内容は自動で保存され、次に開いたときは続きから始まります。保存先はこのパソコンのブラウザの中です（ブラウザの閲覧データを消すと消えます。別のパソコンには引き継がれません）。大事な版は「keymap.c をファイルに保存」でも残してください。

    ファイルとして

    このツールで作った keymap.c は、あとで「読み込む」で続きから直せます。古いソース（wireless_playground）用に作った keymap.c も読み込めます（キー名は自動で新しい名前に直します）。

    ビルドと書き込み
    
      
    キーの割り当て・マクロの作成・保存・下のコマンドの表示は、この keymap_maker.html 1つだけで完結します（他のファイルは不要）。他の人に渡すときも、このファイル1つで大丈夫です。
    
        「保存して焼く」ボタンと q0max_flash.bat は、このパソコンだけの近道です（無くても、下の 2・3 のコマンドを自分でQMK MSYSにコピーすれば同じことができます）。
    
      
    Web版（GitHub Pages）で開いています。「保存して焼く」ボタンは、ダウンロードして自分のパソコンで使う版だけの機能なので、ここでは表示していません。下の「GitHub でビルドする」か、2・3 のコマンドを使ってください。
    
      
    
        
    
          
          QMKのフォルダに保存 → 書き込み用の黒い画面が開き、ビルドと書き込みを自動で行います
        
    
        
    使う前に、このツールと同じフォルダの q0max_ボタン登録.bat を1回だけダブルクリックしてください（このボタンから黒い画面を開けるようにする設定です）。
    
          ボタンで開かないときは、同じフォルダの q0max_flash.bat をダブルクリックしても同じことができます。

    GitHub でビルドする（QMK MSYS が無いパソコン向け）
    
      
    自分用の非公開（Private）リポジトリに keymap.c を上げると、GitHub がビルドして .bin を作ります（作り方は配布元のリポジトリの説明を見てください）。
        keymap.c は自分のパソコンと自分の非公開リポジトリにしか置かれません。公開（Public）のリポジトリには上げないでください（公開リポジトリではビルドしない作りになっています）。
